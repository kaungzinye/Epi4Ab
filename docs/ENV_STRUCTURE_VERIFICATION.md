# Environment Variable Structure Verification

## Required Environment Variables for Upstream Preprocessing

Based on analysis of `run_preprocess.sh` and the individual preprocessing scripts, here are the **required** environment variables:

### Core Variables (Required)

| Variable | Purpose | Used By | Example Value |
|----------|---------|---------|---------------|
| `DIRECTORY_PDB_INFO` | Input CSV file with PDB information | `create_metadata.py` | `${DIRECTORY_INPUT}/pdb_info.csv` |
| `DIRECTORY_PREPROCESS_OUTPUT` | Base output directory for all preprocessing outputs | `create_metadata.py` | `/leonardo_scratch/fast/AIFAC_F01_302/epi4ab/upstream_preprocess` |
| `DIRECTORY_METADATA` | Path to metadata.csv (generated by create_metadata.py) | `main.py`, `nodes_edges.py`, `fill_edge.py` | `${DIRECTORY_PREPROCESS_OUTPUT}/metadata.csv` |
| `DIRECTORY_PROCESSED` | Directory for processed data (pdb_profile.parquet files) | `main.py`, `nodes_edges.py` | `${DIRECTORY_PREPROCESS_OUTPUT}/processed_data` |
| `DIRECTORY_NODES_EDGES` | Directory for nodes_edges output (parquet files) | `nodes_edges.py`, `fill_edge.py` | `${DIRECTORY_PREPROCESS_OUTPUT}/nodes_edges` |
| `PYMOL_EXECUTABLE` | Full path to PyMOL executable | `nodes_edges.py` | `/path/to/pymol` |
| `MAFFT_EXECUTABLE` | Full path to MAFFT executable | `create_metadata.py` | `/path/to/mafft` |

### Helper Variables (Optional but Recommended)

| Variable | Purpose | Used By |
|----------|---------|---------|
| `CURRENT_WORKING_DIRECTORY` | Base project directory | Used in variable expansion |
| `DIRECTORY_INPUT` | Input directory for data files | Used to construct `DIRECTORY_PDB_INFO` |

## Script Usage Mapping

### 1. `create_metadata.py`
```bash
python preprocess/create_metadata.py $DIRECTORY_PDB_INFO $DIRECTORY_PREPROCESS_OUTPUT $MAFFT_EXECUTABLE
```
- **Arg 1**: `$DIRECTORY_PDB_INFO` → `directory_pdb_info` (input CSV)
- **Arg 2**: `$DIRECTORY_PREPROCESS_OUTPUT` → `directory_input_data` (where metadata.csv is written)
- **Arg 3**: `$MAFFT_EXECUTABLE` → `mafft_path`

### 2. `preprocess/main.py`
```bash
python preprocess/main.py $DIRECTORY_METADATA $DIRECTORY_PROCESSED [--download_pdb]
```
- **Arg 1**: `$DIRECTORY_METADATA` → `directory_metadata` (path to metadata.csv)
- **Arg 2**: `$DIRECTORY_PROCESSED` → `directory_output` (where processed data goes)
- **Optional**: `--download_pdb` flag

### 3. `nodes_edges.py`
```bash
python preprocess/nodes_edges.py $DIRECTORY_METADATA $DIRECTORY_PROCESSED $DIRECTORY_NODES_EDGES $PYMOL_EXECUTABLE 'CB'
python preprocess/nodes_edges.py $DIRECTORY_METADATA $DIRECTORY_PROCESSED $DIRECTORY_NODES_EDGES $PYMOL_EXECUTABLE 'CA'
```
- **Arg 1**: `$DIRECTORY_METADATA` → `directory_metadata`
- **Arg 2**: `$DIRECTORY_PROCESSED` → `directory_processed`
- **Arg 3**: `$DIRECTORY_NODES_EDGES` → `directory_nodes_edges`
- **Arg 4**: `$PYMOL_EXECUTABLE` → `pymol_path`
- **Arg 5**: `'CB'` or `'CA'` → `Catom` (atom type)

### 4. `fill_edge.py`
```bash
python preprocess/fill_edge.py $DIRECTORY_METADATA $DIRECTORY_NODES_EDGES
```
- **Arg 1**: `$DIRECTORY_METADATA` → `directory_metadata`
- **Arg 2**: `$DIRECTORY_NODES_EDGES` → `directory_nodes_edges`

## Important Notes

1. **`DIRECTORY_PROCESSED` vs `DIRECTORY_PROCESSED_DATA`**: 
   - ✅ Use `DIRECTORY_PROCESSED` (NOT `DIRECTORY_PROCESSED_DATA`)
   - The scripts expect `DIRECTORY_PROCESSED`

2. **Variable Dependencies**:
   - `DIRECTORY_METADATA` must be `${DIRECTORY_PREPROCESS_OUTPUT}/metadata.csv` (created by `create_metadata.py`)
   - `DIRECTORY_PROCESSED` should be `${DIRECTORY_PREPROCESS_OUTPUT}/processed_data`
   - `DIRECTORY_NODES_EDGES` should be `${DIRECTORY_PREPROCESS_OUTPUT}/nodes_edges`

3. **Executable Paths**:
   - Must be **full absolute paths** to the executables
   - Verify paths exist: `test -f "$PYMOL_EXECUTABLE" && echo "PyMOL found" || echo "PyMOL NOT found"`
   - Verify paths exist: `test -f "$MAFFT_EXECUTABLE" && echo "MAFFT found" || echo "MAFFT NOT found"`
